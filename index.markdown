# Latest forecasts for Nigeria

<img src="/assets/images/lassa-sentinel/storymap-linechart_20260401_100129.png" alt="Forecasts by state">

Time-series charts show in green how well the model fits to confirmed case counts in the training dataset (grey dots), with projections from the latest available cases data shown in purple. We used the conformal prediction algorithm to visualise 67% coverage intervals around the mean model output for each state.

The Moving Epidemic Method was used to derive high and medium epidemic thresholds for each state; these are shown as red and yellow lines respectively. 

The map below shows how the maximum predicted upper bound of the 67% conformal interval in the forecast period compares with the MEM thresholds. 

<img src="/assets/images/lassa-sentinel/storymap-single-map_20260401_100129.png" alt="Forecasts map">
